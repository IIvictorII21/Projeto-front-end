# Planejador de Viagens - Guia de Destinos e Eventos

Projeto desenvolvido para a disciplina de Front-End, focado na criação de um site de planejamento de viagens interativo e estruturado, 
mostrando alguns dos principais destinos turísticos do Brasil e seus grandes eventos culturais.

# Tecnologias Utilizadas

* HTML: Estrutura semântica das páginas e formulários.
* CSS: Estilização visual (seguindo separação de arquivos e sem estilos em linha).
* GitHub: Controle de versão e hospedagem do repositório.

## Estrutura do Projeto

O projeto segue uma organização de pastas para manter o código limpo:

├── index.html
├── index.css
├── /HTML/ # Páginas específicas de cada cidade/destino em html.
├── /CSS/  # As configurações dos estilos globais e específicos das páginas html.
└── /imagens/ # Fotos de eventos e pontos turísticos.
